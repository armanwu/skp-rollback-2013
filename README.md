# SKP Rollback to 2013

A lightweight SketchUp extension that allows users to instantly save a copy of the active model into SketchUp 2013 format (`.skp`).

## Features

- **One-Click Export**: Save active SketchUp models directly to SketchUp 2013 format.
- **Smart File Naming**: Automatically saves a copy with `_v2013.skp` suffix in the same directory.
- **Lightweight & Fast**: Pure Ruby extension without toolbar or UI bloat.

## Installation

1. Download [`skp_rollback.rbz`](skp_rollback.rbz).
2. Open SketchUp and go to **Extensions** > **Extension Manager**.
3. Click **Install Extension** and select the `.rbz` file.

## Usage

Go to **Extensions** (or **Plugins**) > **Save to SketchUp 2013**.
